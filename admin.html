Collegamento a GitHub

L'admin scrive sul repository con le API di GitHub: un solo commit per ogni pubblicazione.

GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token. Dai accesso solo a questo repository e un solo permesso: Contents → Read and write.

Senza la spunta il token resta in memoria finché la scheda è aperta, e sparisce alla chiusura. Non finisce mai dentro un commit: non è un dato del sito.
